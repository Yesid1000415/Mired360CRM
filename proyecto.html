Proyecto de transformación y control comercial

MIRED360CRM

Una solución digital desarrollada para organizar la gestión comercial, respaldar la información entregada al cliente y facilitar el trabajo de los asesores desde un mismo ecosistema.

¿Qué resuelve el proyecto?

Centraliza tareas que normalmente quedan repartidas entre formularios, mensajes y registros independientes, buscando una operación más organizada y trazable.

📋

Gestión comercial

Registro estructurado de los datos necesarios para la gestión de una solicitud, incluyendo cliente, ubicación, asesor, servicio, plan y condiciones comerciales.

✍️

Autorización electrónica

Generación de una constancia única con la información comercial suministrada y la decisión del cliente, con posibilidad de firma en pantalla.

📲

Firma por WhatsApp

El asesor prepara la gestión y puede enviar un enlace individual para que el cliente revise la información y autorice desde su propio celular.

🔒

Control de acceso

El proyecto utiliza autenticación y permisos de base de datos. Las autorizaciones registradas se diseñaron para no ser editadas desde el acceso normal de los asesores.

📄

Constancias consultables

Cada gestión genera un número de constancia y puede conservarse para consulta y generación posterior de una copia imprimible o PDF.

👥

Portal de asesores

Se implementó un acceso operativo separado del panel administrativo para que cada asesor trabaje con las funciones necesarias sin abrir el CRM completo.

Flujo de una autorización

1

Registro

El asesor diligencia datos del cliente, dirección, barrio/conjunto, estrato y condiciones de la venta.

2

Revisión

La información del servicio, valores, promociones y beneficios queda presentada para revisión.

3

Autorización

El cliente responde y firma presencialmente o recibe un enlace individual por WhatsApp.

4

Respaldo

La constancia queda registrada para posterior consulta y descarga desde el entorno autorizado.

OBJETIVO

Menos duplicidad, más organización

La evolución del proyecto busca que el asesor capture la información una sola vez y que esa misma gestión alimente el proceso comercial y su respaldo electrónico, evitando tener que diligenciar por separado una plantilla y luego repetir la información en el CRM.

Estado actual

El flujo principal ya se encuentra operativo: creación de autorizaciones, firma presencial, envío de enlace al cliente por WhatsApp, firma remota, almacenamiento y consulta de constancias. El portal individual de asesores se encuentra preparado para la incorporación de usuarios.
